# 2026-11-04

## 新增 all 一键重建命令（收尾完成）

- `cmd/ip2region/all.go`：`runAll` 按序调 fetch → parse → legacy → enrich → refine →
  merge → build → verify → stats，每步计时、失败即停并报第几步；结尾输出文件大小/md5/总耗时。
  开关：`-skip-fetch` `-skip-legacy` `-skip-enrich` `-skip-refine` `-verify-n`，
  以及 `-db/-txt/-out` 换路径、`-qps/-workers/-probe-*` 透传下游。
- 坑：`fileMD5` 已在 fetch.go 声明，all.go 重复定义导致编译失败（已删除重复实现，复用现成的）。
- 坑：步骤切片里混用匿名 struct 字面量（虽然可赋值给 allStep），统一改成 `allStep{...}`；
  步骤总数改为 `len(steps)`，跳过某些步时不再显示 [3/9] 这种空号。
- `main.go`：注册 `all` 命令 + usage 首行。
- 包装脚本：`rebuild.bat`（Windows 双击）/ `rebuild.sh`（Linux/macOS/Git Bash），
  只做「go build + 调 all」，参数原样透传；bat 双击无参时 pause 停留窗口。
- 关键坑：**bat 必须纯 ASCII**。用 UTF-8 写中文注释/echo，cmd 按 GBK 逐行解码会把多字节字符
  吞掉换行，报 "'full' 不是内部或外部命令" 之类。已改成英文提示。
- 新增 `.gitattributes`：`*.bat eol=crlf`、`*.sh eol=lf`、`*.go eol=lf`。
  core.autocrlf=true 会把 .sh 转成 CRLF，Linux 上会 bad interpreter，必须钉死。
- 验证：临时库跑 `all -skip-fetch -skip-enrich -skip-refine -skip-legacy` → 29~31 秒出
  22MB xdb，verify/stats 全通过；`rebuild.bat`/`rebuild.sh` 均实测可跑。
- README 增补「一键重建」章节、命令总览加 all 行、修复 merge 标题重复的排版 bug。

注意：`all` 里的 parse 会重建段表，手工改过 SQLite 段表会被覆盖（自定义规则在 merge 阶段重叠加）。
