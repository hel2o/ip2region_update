# 2026-11-03

## ip2region 归属库重写（阶段 0 完成）

**目标**：qqwry.dat → ip2region xdb，用百度 API 提升省市/ISP 精度，叠加自定义 CIDR 覆盖。
输出区域串 6 段：`国|省|市|区|镇|ISP`（示例 `中国|广东省|广州市|番禺区|钟村|中国电信`）。

### 关键结论
- 百度 opendata 接口 `https://opendata.baidu.com/api.php?query=<ip>&co=&resource_id=6006&oe=utf8`
  免费、无 AK、无配额限制；实测 30 并发 2 秒全 200。返回 `data[0].location` = `<省市连写> <ISP>`。
  **只到城市级**（偶尔到区，如百度自己的 IP），**给不出区镇**。
- 因此：区/镇 100% 来自 qqwry；百度只用于纠正省市 + 校验 ISP。
  反面教材 = 旧 `ip2region.go` 的"API 查不到就整段覆盖"，会把区镇抹空。
- `北京市北京市` 这类省市重复、`广东省深圳市 电信` 这类省市连写，必须有行政区划字典做最长前缀切分（阶段 3）。
- region 是 6 段，官方 SDK 的 `Region` 按 5 段解析，**查询侧不能直接用官方便捷方法**。

### 架构决策
- 运行形态：单机 + SQLite（段表 / ip_cache / overrides），断点续跑 + 重跑零请求。不上 Redis。
- 自定义覆盖：纯文本 CIDR 表 `data/custom/*.txt`，每行 `CIDR|区域串`，优先级最高。
- 请求量控制靠**二分收敛**（段内 mid 一致则整段确认），不靠限流堆并发。
