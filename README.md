# ip2region_update

自建的 IPv4 离线归属地数据库（ip2region xdb 格式），定期重建发布。以纯真库为基础，
融合多个数据源补齐省市、区县与运营商信息，**全量覆盖 42.9 亿个 IPv4 地址**。

**数据文件在 [Releases](../../releases) 页面下载**（每版一个 `ip2region_<版本>.xdb`，约 60MB），
仓库本身不存放 xdb。当前最新版本 **20261108**。

> 版本号取自库内探针（见下文「版本识别」），文件名即版本，下载最新 Release 里的 xdb 即可。

## 区域格式：6 段

区域串用 `|` 分隔，共 **6 段**（注意：不是 ip2region 官方默认的 5 段，直接用官方 SDK
的 5 段便捷解析会字段错位，请按下表自行切分）：

```
中国|广东省|广州市|番禺区|钟村|中国电信
 0     1      2     3     4     5
国家    省     市    区县   乡镇   ISP
```

- 空字段表示该级无数据（区县、乡镇缺失较常见）
- 境外 IP 的省/市位放境外行政区划（如 `日本|大阪府|大阪市`），ISP 段可能是英文公司名

Go 查询示例（官方 binding）：

```go
import "github.com/lionsoul2014/ip2region/binding/golang/xdb"

searcher, _ := xdb.NewWithFileOnly("ip2region_20261108.xdb")
defer searcher.Close()

region, _ := searcher.SearchByStr("14.215.177.38")
// → "中国|广东省|广州|||中国电信"

parts := strings.SplitN(region, "|", 6)
// parts[0] 国家  parts[1] 省  parts[2] 市  parts[3] 区县  parts[4] 乡镇  parts[5] ISP
```

高并发场景建议用 `xdb.LoadContentFromFile` 读进内存后走 `NewWithBuffer`（库约 60MB，
全内存查询）；用文件句柄方式必须重启进程才能换库。

## 版本识别

`255.255.255.255` 是广播地址，永不命中真实查询，用它做版本探针：

```go
region, _ := searcher.SearchByStr("255.255.255.255")
// 老库返回 "纯真网络|||||保留地址"
// 本库返回 "|20261108|2026-11-08 09:51|||"（省位=版本日期，市位=生成时刻）
```

加载端可据此判断当前加载的是哪一版数据。

## 数据来源

| 层级 | 来源 | 说明 |
|---|---|---|
| 基础底库 | [纯真 qqwry.dat](https://github.com/metowolf/qqwry.dat) | 全量 IPv4 底表，境外与省市主干来源 |
| 省 / 市 / ISP 补空 | 百度 IP 画像接口 | 对国内网段采样探测，补齐 qqwry 缺失的省、市、ISP |
| 区县 | [GeoCN](https://github.com/ljxi/GeoCN) | 唯一能到区县级的源，按其网段边界切分补空，并要求与省市自洽 |
| ISP 归属 | [APNIC 分配网段表](https://ispip.m27.tech) | 运营商网段分配记录，只补空不覆盖（云厂商/IDC 优先于基础运营商） |
| 港澳台归属 | [ispip 港澳台网段表](https://ispip.m27.tech) | 港/澳/台全量 CIDR，归属优先级仅次于人工规则；ISP 取百度结果 |
| 境外省市 | 历史版本库回填 | 新版纯真库简化了境外记录，从旧版库搬回 |
| 人工覆盖 | 自维护 CIDR 规则 | 少量探测/分配都不准的网段手工修正 |

构建原则：

- 省/市以探测结果为准（qqwry 标签常滞后于网段重分配）
- 云 / CDN / IDC 段不覆盖省市——这些段的流量落点由路由决定，探测只能得到 PoP 城市
- ISP 以探测结果为主，网段表只在为空时补（港澳台反过来：百度有值就用百度）
- 区县只补空、不改动，且必须与已有省市自洽
- 区/镇字段完全来自原始库，无可靠来源时不做修改

## 覆盖率（按 IP 数加权，中国 IP）

| 字段 | 覆盖率 |
|---|---|
| 省 | 99.49% |
| 市 | 98.01% |
| 区县 | 44.00% |
| 乡镇 | 11.24% |
| ISP | 96.26% |

- 国内 IP 约 4.06 亿（占 IPv4 全域 9.5%），划分为约 149 万个归属段
- 乡镇覆盖率低是数据源天花板——没有任何公开源提供乡镇级数据
- 全库无重叠、无缝隙，任意 IPv4 地址均可返回结果（含保留地址段）

## 更新频率

不定期重建发布，一般随基础库更新或规则调整后重新构建。文件按版本号命名，
旧版本随新版本发布一并移除。
