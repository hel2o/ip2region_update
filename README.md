# IP2Region XDB 数据库更新说明（2025-07-21）

本项目为 **IP2Region** 的本地数据库 `.xdb` 文件更新版本，提供了三种不同来源构建的数据库文件，用于满足不同场景下的 IP 地址定位需求。

---

## 📁 提供的 XDB 文件列表

| 文件名                            | 数据来源            | 描述                                               |
|--------------------------------|-----------------|--------------------------------------------------|
| `ip2region_20250721_i.xdb`     | qqwry + 爱奇艺 API | 原始数据来自 qqwry 纯真库，结合其网段信息调用 **爱奇艺 API** 查询补充数据    |
| `ip2region_20250721_m.xdb`     | qqwry + 美团 API  | 原始数据来自 qqwry 纯真库，结合其网段信息调用 **美团 API** 查询补充数据     |
| `ip2region_20250721_qqwry.xdb` | qqwry           | 原始的 qqwry 纯真库数据，**未经过外部 API 补充**，直接转换为 `.xdb` 格式 |

---

## 📌 使用建议

| 场景            | 推荐文件                           | 说明                        |
|---------------|--------------------------------|---------------------------|
| 需要结合爱奇艺数据补充   | `ip2region_20250721_i.xdb`     | 更适合爱奇艺生态或相关业务系统           |
| 需要结合美团数据补充    | `ip2region_20250721_m.xdb`     | 更适合美团生态或本地生活类业务           |
| 仅需原始 qqwry 数据 | `ip2region_20250721_qqwry.xdb` | 适用于通用 IP 查询，不依赖第三方 API 补充 |

---

## 📚 项目说明

- **IP2Region** 是一个轻量级、高效的离线 IP 地址定位库，支持多种语言绑定（如：Java、Python、PHP、Go 等）。
- 所有数据均基于本地 `.xdb` 文件进行查询，速度快、资源占用低。
- 本次更新基于 `qqwry` 纯真库数据，并结合不同业务平台的 API 查询结果进行数据增强，提升定位准确性。

---

## 📝 注意事项

- 若需验证数据库准确性，建议使用 `ip2region` 提供的命令行查询工具或对应语言的 SDK 进行测试。
- 建议根据自身业务平台选择对应的 XDB 文件（如：爱奇艺业务优先使用 `_i.xdb`，美团业务优先使用 `_m.xdb`）。
- 原始纯真库文件（`qqwry`）未经过外部补充，适用于对第三方数据依赖敏感的场景。
