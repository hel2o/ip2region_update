# 自定义覆盖规则

本目录下所有 `*.txt` 都会在 `merge` 阶段叠加，**优先级最高**，覆盖 qqwry 与百度的一切结论。

## 格式

每行一条，`#` 开头为注释，空行忽略。支持两种地址写法：

```
# CIDR 写法
181.0.0.0/12|中国|广东省|广州市|番禺区|钟村|中国电信

# 起止 IP 写法
1.2.3.0|1.2.3.255|中国|北京市|北京市|||中国联通
```

区域串固定 6 段：`国|省|市|区|镇|ISP`，字段不足 6 段自动右补空；
**字段内容里不能出现竖线**（超过 6 段会直接报错，避免静默错位）。

## 规则

- 同一个 IP 被多条规则命中时，靠后的行胜出
- 覆盖段会把原有的段切开，覆盖范围之外的归属不受影响
- `merge` 会自动校验合并结果的全覆盖与连续性，失败即报错
